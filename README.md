# Градітекст

Перетворює будь-який текст (до 600 знаків) на градієнтне полотно. Кожна літера має власний унікальний градієнт, а між літерами, пробілами й розділовими знаками стоять плавні конектори: світловий шов, подих, вузол, спалах, поворот, відблиск тощо.

Сайт лежить у папці `docs/`. Щоб запустити локально, відкрий `docs/index.html` у браузері. Залежностей немає.
