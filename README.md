# Градітекст

Перетворює будь-який текст (до 600 знаків) на градієнтне полотно. Кожна літера має власний унікальний градієнт, а між літерами, пробілами й розділовими знаками стоять плавні конектори: світловий шов, подих, вузол, спалах, поворот, відблиск тощо.

Сайт лежить у папці `docs/`. Щоб запустити локально, відкрий `docs/index.html` у браузері. Залежностей немає.

## Англійська версія

`docs/en/index.html` не редагується вручну: його генерує `scripts/build_en.py` з української сторінки (переклад усіх рядків + SEO-теги для `/en/`). Деплой запускає скрипт автоматично. Якщо змінюєш український текст, додай переклад у список `PAIRS` у скрипті, інакше збірка впаде й покаже, який рядок не перекладено.

```bash
python3 scripts/build_en.py
```
